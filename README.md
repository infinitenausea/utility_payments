# Расчёт коммунальных платежей (Настя Толя и Алёна Айрат)

Легковесное приложение для расчёта коммунальных платежей в грузинских лари (₾).
Работает как полностью автономный один HTML-файл (без серверов и зависимостей), а также поддерживает локальный запуск на Python или публикацию на GitHub Pages.

## Варианты использования

### 1. Как автономный файл (без установки чего-либо)
Просто откройте `index.html` двойным кликом в любом браузере на любом компьютере или телефоне. Ничего устанавливать не нужно.

### 2. Через GitHub Pages (веб-ссылка для соседей)
1. Создайте репозиторий на GitHub и отправьте в него файлы:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
2. В репозитории на GitHub перейдите в **Settings** $\to$ **Pages**.
3. В поле **Branch** выберите `main` и папку `/(root)`, нажмите **Save**.
4. Через минуту у вас будет готовая ссылка вида `https://<ваш-логин>.github.io/<имя-репозитория>/`, которую можно отправить соседям.

### 3. Локальный запуск через Python
- **macOS**: дважды кликните по `start.command`
- **Windows**: дважды кликните по `start.bat`
- **Терминал**: `python3 app.py` (или `python app.py`)

## Что делает приложение
- Принимает прошлые и текущие показания счётчиков **электричества** и **газа** для двух домов (поддерживает и точку, и запятую в дробных числах).
- Рассчитывает расход каждого дома и пропорционально делит отдельные счета за свет и за газ.
- Делит счета за **воду** и **мусор** поровну на 2.
- Формирует компактную итоговую карточку со всеми исходными показаниями, расходом, процентами и суммами — готовую для одного скриншота в мессенджер.
